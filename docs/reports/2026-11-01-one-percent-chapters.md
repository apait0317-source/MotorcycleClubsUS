## Research decisions

- Retained separate named chapters within the same city; deduplication includes chapter name, city and state.
- Kept regional, county, nomadic and prospective labels out of city fields. No street addresses or coordinates were guessed.
- Used only the Florida-origin Warlocks roster. Pennsylvania/Delaware Valley Warlocks remain a separate unresolved research gap.
- Did not promote historical law-enforcement reports into current chapter listings. The 2025 Mongols Edgewater report remains a research lead.
- Excluded a combined Sons of Silence / Handlebar Jockeys Maps listing: the official Sons site lists Handlebar Jockeys as a support club, so it cannot establish a Sons chapter.
- Bandidos’ linked US site could not be retrieved; Pagans had no verified current public roster. Their pages explain coverage gaps.
- Source review dates record retrieval/review, not roster publication dates or confirmation of current operations.

## Validation

- All 180 tests passed under Node 22, using a direct `node --import tsx` runner importing every test file. The sandboxed `tsx --test` launcher could not create its IPC pipe; direct execution ran the actual named tests.
- TypeScript check, application ESLint and `git diff --check` passed.
- Production build passed and generated 3,442 static pages. The first sandboxed attempt could not fetch the existing Google Fonts dependency; the network-enabled retry succeeded.
- Inspected all eight generated organization pages: expected city/state-only counts, state anchors, noindex for pending city-coverage hubs, and absence of internal chapter evidence in public HTML.
- Independent evidence review matched all city entries to source captures. Independent final code review found no actionable issues and checked 104 state anchors, source disclosure, profile eligibility and sitemap behavior.
- No browser interaction, external chapter contact or production deployment was performed.

## Maintenance

Reviewed data lives in `data/verified-chapters.json`. Each chapter references a declared source with an actual review date and internal supporting evidence. The loader validates dates, URLs, states, identities and existing profile references. Public pages show source links and coverage notes, not internal evidence notes.

For a refresh, read the cited sources again, update only supported facts and actual review dates, preserve chapter IDs and existing profile URLs, and run the test suite, typecheck, lint and production build. Recheck Vagos source integrity before relying on its roster.

No production deployment is part of this change.
